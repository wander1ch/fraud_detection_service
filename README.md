# Fraud Detection Service (Сервис обнаружения мошенничества)

Высокопроизводительный микросервис на языке Go, предназначенный для обнаружения потенциально мошеннических транзакций в режиме реального времени. Сервис считывает данные о транзакциях из Apache Kafka, оценивает их на основе настраиваемых правил и отправляет уведомления через вебхуки при обнаружении подозрительной активности.

## Стек технологий
- **Язык:** Go
- **Очереди сообщений:** Apache Kafka
- **База данных:** PostgreSQL (для истории транзакций и хранения)
- **Кэширование:** Redis (для быстрого доступа к состоянию/истории)
- **Конфигурация:** Переменные окружения (`.env`)

## Основные возможности
- Мониторинг транзакций в реальном времени.
- Механизм правил (например, проверка лимитов сумм).
- Автоматические уведомления через вебхуки для помеченных транзакций.
- Корректная обработка завершения работы (Graceful Shutdown).
- Структурированное логирование (zap).

## Начало работы

### Требования
- Go 1.22+
- Docker & Docker Compose
- Доступ к Kafka, PostgreSQL и Redis

### Конфигурация
Скопируйте файл с примером переменных окружения и настройте его под вашу инфраструктуру:
```bash
cp .env.example .env
# Отредактируйте .env, указав ваши переменные окружения
```

### Запуск сервиса
```bash
# Сборка и запуск с помощью Docker Compose
docker-compose up --build
```

## Проверка работоспособности

Вы можете проверить работу сервиса, имитируя данные о транзакциях.

### 1. Мониторинг логов
Проверяйте логи сервиса, чтобы увидеть, когда он запускается и когда происходит оценка транзакций:
```bash
# При запуске через docker-compose
docker-compose logs -f app
```

### 2. Тестирование входящих данных Kafka
Отправьте тестовое JSON-сообщение в Kafka-топик `transactions`:
```json
{
  "transaction_id": "test-123",
  "amount": 15000,
  "currency": "EUR"
}
```

### 3. Тестирование вебхуков
Сервис отправляет `POST`-запрос на настроенный URL вебхука, когда срабатывает правило обнаружения мошенничества.
1. Перейдите на [https://webhook.site/](https://webhook.site/).
2. Скопируйте ваш уникальный URL.
3. Обновите URL в `cmd/app/main.go` или в вашем файле `.env` (если реализовано чтение из файла).
4. Если транзакция нарушает правило (например, сумма > 10 000 EUR), вы мгновенно увидите JSON-алерт на панели управления Webhook.site.
